F:st — Menu
===========

The menu lists the actions available given the cursor item (or currently selected items).

Type to filter the list, or type an item's alias letter (in bold) to run that item
immediately. Custom items from actions.toml appear after the builtins.

Keys
----
| action | bind | description |
|--------|------|-------------|
| ShowMenu | | close the menu |
| Accept | | run the highlighted item |
| Up(1) | | move up |
| Down(1) | | move down |
| Help | | show this document |
| Quit(1) | | close the menu |

Action Guidance
---------------
Execute
  The prompt is a command template: {} is the current item and {+} every
  selected item.

New / New folder
  New creates a file unless the name ends in a separator, which creates a
  directory. New folder always creates a directory; a trailing separator also
  jumps into it.
